# somnia-derive

`#[derive(SurrealRecord)]` proc-macro for the
[`somnia`](https://crates.io/crates/somnia) SurrealDB ORM. Generates typed column
accessors, table metadata, and `DEFINE TABLE`/`DEFINE FIELD` schema DDL from a
Rust struct.

Use via the umbrella [`somnia`](https://crates.io/crates/somnia) crate.
